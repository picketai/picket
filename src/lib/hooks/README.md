# Hooks

Listed in `src/lib/hooks.mts`; the build generates `hooks.json` in `dist/hooks/` from that list, and Claude Code loads it with the plugin. `guard.*` deny or bounce, `lint.*` and `monitor.*` feed text back, `observe.*` and `emit.*` record, `inject.*` add context. Every hook exits 0 on its own failure except where a deny is the point; a hook must start in under 200 ms cold (`test/timing/budgets.test.mjs`).

| Hook | Event | Does |
|---|---|---|
| `inject.state.mjs` | SessionStart | open work items with their next action, plus `.claude/MEMORY.md` |
| `inject.rules.mjs` | SessionStart, SubagentStart | the five rules in `rules/`, joined, for the lead and every agent |
| `inject.extensions.mjs` | SessionStart, SubagentStart | each enabled extension's rules and its additions for the lead or the starting agent's role, in config order, within 10,000 characters; one line per refused extension |
| `guard.scope.mjs` | PreToolUse Write, Edit | denies writes to kernel-owned files (`work/*/state.yaml`, `phases/`, `verdicts.jsonl`, `comments.jsonl`, `waivers.jsonl`, `.picket/state/` except `branching.yaml`); denies an Edit on a file this transcript never read |
| `guard.comments.mjs` | PreToolUse Write, Edit | denies an edit that adds a comment line to a code file (detector in `lib/shared/comments.mjs`, doc comments included), unless `picket comment` recorded the user's approval for that path and text on an open or blocked item |
| `guard.silenced.mjs` | PreToolUse Write, Edit | denies an edit that adds a silenced check: a suppression in a code file, a skipped or focused test in a test file, or a coverage or warning threshold made weaker than before or than `quality` in the config (detector in `lib/shared/silenced.mjs`), unless `picket waive` recorded the user's approval for that path and line on an open or blocked item |
| `guard.bash.mjs` | PreToolUse Bash, PowerShell | the command evaluator in `guard/bash/`: one rule table keyed by command root (`ROOTS` in `guard/bash/rules.mts`) says which roots are read-only, destructive or run other commands, which flags make a reader write a file or run a program (`find -fprint`, `tree -o`, `rg --pre`; `git --output` too), which are inert inside `$(...)` and which may read a protected source; read-only commands allowed, destructive roots denied, project tools (`tsc`, `eslint`, `vitest` and the like), compound and redirected commands prompt; a PowerShell command is read by `lib/shared/shell/powershell.mts` and is only ever denied or passed on, never allowed; `picket waive` and `picket comment` from a spawned agent are denied, since they record the user's approval, also inside `eval`, `sh -c`, `xargs`, `env`, `timeout`, `command`, `exec`, `nice`, `Invoke-Expression`, `pwsh -c` and `cmd /c`; a shell write (`>`, `>>`, `>|`, `tee`, `sed -i`, `Set-Content` or `sc`, `Add-Content` or `ac`, `Out-File`), direct or inside one of those wrappers, from a spawned agent to a code or test file inside the project, outside `.picket/state/`, is denied, so `guard.comments` and `guard.silenced` see every code edit an agent makes; a command marked with `PICKET_ESCALATE` asks in the modes listed in `lib/shared/escalation.mts` (default, acceptEdits, auto) |
| `lint.schema.mjs` | PostToolUse Write, Edit under `work/` | order and design artifacts: frontmatter, phase headings, decision ids, caps, placeholders, revision protocol against git HEAD |
| `observe.drive.mjs` | PostToolUse Bash, PowerShell | appends drive or inspect rows to `.picket/state/drive-log.jsonl` with the current work item (the most recently active open or blocked item, this session's first) and its phase; `picket next --latest` answers that same item, and `picket verify` reads the rows |
| `monitor.context.mjs` | PostToolUse Read, Grep, Glob, WebFetch, WebSearch | the stall detector: six look-around calls with no action get one line of context |
| `guard.block.mjs` | Stop, SubagentStop | a turn with a contract heading must end with an exact verdict token and stay within 40 lines |
| `route.verdict.mjs` | Stop, SubagentStop | applies the verdict to the work item with the kernel and hands back `picket next` as context |
| `emit.ledger.mjs` | Stop, SubagentStop | one v2 ledger row per turn (`bench/schema/ledger-v2.schema.json`) |
| `notify.user.mjs` | Notification permission_prompt, idle_prompt | an OS notification in a detached process (a Windows toast through powershell.exe, osascript, notify-send); `PICKET_NOTIFY=off` skips it |

Every hook, guards included, is a folder `src/lib/hooks/<kind>/<name>/` whose `index.mts` exports `hook`, a `HookSpec` (`hook-spec.mts`): a handler that takes the event and a context and returns an output built with `output.mts`, or `null`. Code one hook uses stays in its folder, code one kind shares sits in the kind folder (`guard/edit-target.mts`), and no hook imports another. For each name in the list the build generates the entry `runHook("<name>", hook)` (`run-hook.mts`), which checks the Node version, reads stdin, prints, records a denial in the ledger, swallows errors and exits 0.

Libraries: `src/lib/shared/transcript/` (`tail.mts` reads a transcript from its end, `entries.mts` holds spawn hints, tool statistics and the read-before-edit lookup, `turn.mts` the turn's block text and span, `agent.mts` the agent's name and transcript), `src/lib/hooks/observe/drive/evidence.mts` (kept from the earlier copy-in version for its tested parsers), `src/lib/shared/sources/protection.mts` (what a source protects), `src/lib/shared/shell/powershell.mts` (the PowerShell reader `guard.bash` and `observe.drive` use for the PowerShell tool), `src/lib/shared/shell/kernel-call.mts` (where a `picket` call starts in a command), and `src/lib/util/vendor/shell-quote-parse.mjs`, the tokenizer `guard.bash` uses for Bash.

At build time each generated entry is bundled with everything it imports into one file, `dist/hooks/<kind>.<name>.mjs`, so a hook opens one module, not one per import. Standalone, run the bundle: `node dist/hooks/<hook>.mjs < payload.json`. Tests: each handler's tests sit beside its modules (`guard/bash/index.test.mts`); `test/hooks/<kind>.<name>.test.mjs` spawns the bundle (`test/hooks/guard.bash.test.mjs`).

A blocked call or a bounced turn is Picket working. Fix the violation; do not retry variants.
