# Mods

Generated by `npm run docs` from `src/lib/mods.mts`; edit the source, not this page.

The mods ship inside the `picket` plugin and load with it. A mod with an off switch turns off when `.picket/config.json` sets that key to `false`, from the next session.

| Mod | Off switch | Does |
|---|---|---|
| status | none | a band above the prompt with the open work item, its next action and its running agents, and a work pane (/picket-session) listing this project's sessions by what they need |
| markdown | `mods.markdown`: false | a read-only pane beside the transcript for a Markdown path clicked in a reply |
