# Mods

Generated by `npm run docs` from `src/lib/mods.mts`; edit the source, not this page.

| Mod | Plugin | Installed | Does |
|---|---|---|---|
| status | `picket-status` | by `picket init` | a band above the prompt with the open work item, its next action and its running agents, and a work pane (/picket-session) listing this project's sessions by what they need |
| markdown | `picket-markdown` | by `picket init` | a read-only pane beside the transcript for a Markdown path clicked in a reply |
| session | `picket-session` | on request | retired: the session list is now the work pane of picket-status; uninstall it |

Install an opt-in mod from the project root:

```sh
claude plugin install picket-session@picketai --scope project
```
