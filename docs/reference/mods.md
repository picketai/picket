# Mods

Generated by `npm run docs` from `src/lib/mods.mts`; edit the source, not this page.

The mods ship inside the `picket` plugin and load with it. When `.picket/config.json` sets an off switch to `false`, it turns off its mod, or only the part its row names, from the next session.

| Mod | Off switch | Does |
|---|---|---|
| status | `mods.session`: false turns off the work pane only | a band above the prompt with the open work item, its next action and its running agents, and a work pane (/picket-session) listing this project's sessions by what they need |
| markdown | `mods.markdown`: false | a read-only pane beside the transcript for a Markdown path clicked in a reply |
