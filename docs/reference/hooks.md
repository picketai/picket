# Hooks

Generated by `npm run docs` from `src/lib/hooks.mts`; edit the source, not this page.

Each hook name starts with its kind. `guard.*` hooks deny a tool call or bounce a turn, `lint.*` and `monitor.*` feed text back to the model, `observe.*` and `emit.*` record what happened, `inject.*` add context when a session or an agent starts, `route.*` applies a verdict and `notify.*` tells the user.

| Hook | Events | Matcher | Does |
|---|---|---|---|
| `inject.state` | SessionStart |  | open work items with their next action, plus the host folder's `MEMORY.md` |
| `inject.rules` | SessionStart, SubagentStart |  | the five rules in `rules/`, joined, for the lead and every agent |
| `inject.extensions` | SessionStart, SubagentStart |  | each enabled extension's rules and its additions for the lead or the starting agent's role, in config order, within 10,000 characters; one line per refused extension |
| `guard.scope` | PreToolUse | `Write\|Edit` | denies writes to kernel-owned files (`work/*/state.yaml`, `phases/`, `verdicts.jsonl`, `comments.jsonl`, `waivers.jsonl`, `.picket/state/` except `branching.yaml`); denies an Edit on a file this transcript never read |
| `guard.comments` | PreToolUse | `Write\|Edit` | denies an edit that adds a comment line to a code file, doc comments included, unless `picket comment` recorded the user's approval for that path and text on an open or blocked item |
| `guard.silenced` | PreToolUse | `Write\|Edit` | denies an edit that adds a silenced check (a suppression, a skipped or focused test, a weaker coverage or warning threshold), unless `picket waive` recorded the user's approval for that path and line on an open or blocked item |
| `guard.bash` | PreToolUse | `Bash\|PowerShell` | the command evaluator: read-only commands allowed, destructive roots denied, compound and redirected commands prompt; PowerShell is only ever denied or passed on; lead-only verbs and agent shell writes to code are denied; `PICKET_ESCALATE` asks |
| `lint.schema` | PostToolUse | `Write\|Edit` | order and design artifacts: frontmatter, phase headings, decision ids, caps, placeholders, revision protocol against git HEAD |
| `observe.drive` | PostToolUse, PostToolUseFailure | `Bash\|PowerShell` | appends drive or inspect rows to `.picket/state/drive-log.jsonl` with the current work item and its phase; `picket verify` reads the rows |
| `monitor.context` | PostToolUse | `Read\|Grep\|Glob\|WebFetch\|WebSearch` | the stall detector: six look-around calls with no action get one line of context |
| `guard.block` | Stop, SubagentStop |  | a turn with a contract heading must end with an exact verdict token and stay within 40 lines |
| `route.verdict` | Stop, SubagentStop |  | applies the verdict to the work item with the kernel and hands back `picket next` as context |
| `emit.ledger` | Stop, SubagentStop |  | one v2 ledger row per turn (`bench/schema/ledger-v2.schema.json`) |
| `notify.user` | Notification | `permission_prompt\|idle_prompt` | an OS notification in a detached process (a Windows toast through powershell.exe, osascript, notify-send); `PICKET_NOTIFY=off` skips it |
