Package the picket-markdown mod into this repository next to the existing picket-status and picket-session mods, install it locally, and make picket init install it by default like those mods.

The mod is a Claude Code hooks-module plugin: a pane docked beside the transcript that opens markdown files clicked in replies (or opened with /md <path>), read-only, with a file tree of the session's referenced .md files (folders collapsed except the open file's), an outline, per-heading section copy and "ask about this section" (quotes the section into the prompt), back history, per-file scroll memory, auto-reload with change markers, wide table horizontal scrolling, front matter drawn as a table, a work item status line for files under work/<id>/, and open-in-editor.
