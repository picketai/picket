## Phase 2 of 20261110-picket-updates-from-inside-the-session: Init records the Picket version

`picket init` now records the running version as `picket_version` in `.picket/config.json`. If the file is missing, init creates it. If the file exists, init sets the key in place and keeps the other keys, their order and the file's line endings. A file that is not valid JSON fails the step and stays byte for byte as it was. The config loader reads the key, and `picket --version` reads the version through the new `picketVersion()`.
