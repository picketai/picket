Picket updates without npx: keep the inline settings marketplace and the one-time `npx @picketai/picket@alpha init` per project, but make updates happen inside the session. 1. The marketplace entry init writes sets "autoUpdate": true; first check whether Claude Code honours autoUpdate on a settings-source marketplace, and if not, the message below names `/plugin update picket@picketai`. 2. init records the Picket version it ran in .picket/config.json. 3. A session-start check compares that version with the running plugin's version and, on a mismatch, tells the user once: "Picket updated to X; run `picket init` to refresh this project." It only tells, it never rewrites files itself. 4. Update docs/how-to.md's update section to this path, with no npx and no restart for updates.
