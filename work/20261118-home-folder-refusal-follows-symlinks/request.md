picket init does not refuse the home folder when HOME is reached through a symlink. isHomeFolder (src/lib/shared/install.mts) compares the chosen root with HOME as text, so with HOME=/home/vlad/Work/x (a symlink to /mnt/work/x) and the cwd resolved to /mnt/work/x, init sets up the home folder and exits 0. The same check guards picket uninstall. Compare the real paths so the refusal holds. This is also why test/cli/init.test.mjs:104 fails when TMPDIR lies under a symlinked folder, which leaves npm test red and picket mutate at "baseline red".
