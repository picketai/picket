Decisions:
- I handled the issue phase 1 flagged by changing `wordQuotings`. When a word starts with a `{name}` placeholder, the two forms that split off the first character treat the whole placeholder as that first unit: `{source}''/a` and `$'{source}\x2fa'`. For a bare placeholder the hex form is skipped. No existing seed starts with a placeholder, so other closures get the same spellings as before.
- `source path spellings`: the trailing slash applies only to a word that is exactly `{source}` (`git -C {source}/`), because a file path with a trailing slash is refused by `touch` and `cp`. `--target-directory={source}` applies only to a `cp` or `mv` seed whose last word is `{source}/<name>`. The run creates `sub` in the source so that `sub/..` resolves.
- `PowerShell names` qualifies `Format-Volume` and `Clear-Disk` with `Storage\`, their real module, and every other cmdlet with `Microsoft.PowerShell.Management\`. D-002 names only the Management module, and qualifying a Storage cmdlet with it would fail in PowerShell. Forms equal to the seed (the lower case of `rm`) are left out.
- pwsh is not installed on this host, so I could not run the PowerShell spellings (OQ-003 fallback). They follow the PowerShell language reference.
- The escalation runs pass `session: "s"`. The escalation closures read `ASKING_MODES` from the shared module rather than copying the mode list.
