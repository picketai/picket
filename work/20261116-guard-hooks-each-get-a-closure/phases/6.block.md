Decisions:
- The continuation form (a line starting `.skip(`, `?.only(` and so on) counts only in JavaScript and TypeScript files, because `.only(` starts a common Django query chain in Python tests.
- The bracket form is matched on the raw line, because `maskStrings` blanks the member name inside `["skip"]`. It counts only when the masked line still shows `object[` outside a string, so `'it["skip"]('` inside a string literal is no move. The tests now receive `{ masked, text, rel }`.
- node:test options count only inside a call's parentheses (`test("a", { skip: true }, …)`), and `todo` only when it is `true`, so an ordinary `{ skip: 10 }` or `{ todo: "buy milk" }` in test data is no move.
- `SKIP_APIS` splits mocha, jest and vitest: `test.todo` belongs to jest and vitest only, `it.skipIf` to vitest only. `test file names` renames per language (script, Python, Go, C#, Java, Rust), and Rust has only `tests/` forms.
