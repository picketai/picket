When an agent writes a file (ARTIFACT WRITTEN, AMENDED, REPORT WRITTEN), the route hook shows the user a notice with the path, but that notice is plain text Claude Code draws, so it is not a link. The Markdown mod turns a .md path in the lead's own reply into a link that opens the file in its side pane. Make the route hook's context to the lead ask it to print the written path on its own line in its reply (for example "Order: work/<id>/order.md"), so the path becomes clickable.
