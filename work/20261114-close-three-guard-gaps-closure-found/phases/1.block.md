## Phase 1 of 20261114-close-three-guard-gaps-closure-found: The in-place guard sees Perl write modes and skips value flags

The in-place guard now catches Perl `open` calls that write, and it skips Python and Node flags that take a value before deciding whether standard input is the program. All 12 new closure seeds were open on the base `d961c546` and are closed now.

**Red:** in-place guard stays closed under as written failed: in-place guard is open under as written for:

**Root cause:** the guard missed these writes because `WRITE_CALL` knew only Python-style mode letters (`'w'`, `'a'`), and `readsStdin` took the value of a flag such as `-X utf8` or `--require ./x.js` for a script file.

**Changes:**
- `src/lib/hooks/guard/bash/in-place.mts`:
  - `WRITE_CALL` gains one alternative (D-001): `\bopen[ \t]*\(?[^;)\n'"]*['"](?:>|\+[<>])`. The first quoted literal after `open`, in the same statement, must start with `>`, `+<` or `+>`.
  - `programWrites` strips a leading `+<`, `+>`, `>>`, `>` or `<` from each literal (`withoutModePrefix`) and drops a literal left empty.
  - `readsStdin(root, args)` reads a value-flag table per interpreter (D-002), using a new helper `namesScriptFile`.
  - `programText` passes the root to `readsStdin`.
- `in-place.variants.test.mts`: `REVIEW_PROBES` is renamed to `AS_WRITTEN_SEEDS` (D-003) and gains the 12 seeds listed under **Changes**, each spelled in full.
- `in-place.test.mts`: two new tests, one for T-1.3 and one for T-1.4.
- `payloads.test.mts`: one new test for T-1.5. It checks the lead's denial for the four commands.
- No existing case in any of these files was edited.
